# AuraOS

Assistente AI cognitivo, 100% locale. Nessun cloud, nessuna telemetria: gira
sul tuo hardware, i tuoi dati restano sul tuo hardware.

Questa edizione è composta da **server + interfaccia web (PWA)**: si
installa su un PC, e si usa da browser (anche da telefono/tablet in rete
locale, come pagina web — non richiede un'app nativa).

## Cosa fa

- Voce attiva (ascolto continuo + risposta parlata) e chat testuale in
  parallelo, dall'interfaccia web
- Memoria a lungo termine cifrata, che impara da come usi l'assistente
- Riconoscimento del parlante: risponde solo al proprietario
- Ricerca web isolata e controllata, senza esporre dati personali

## Requisiti

- PC con GPU dedicata consigliata (funziona anche solo CPU, con modelli più
  piccoli)
- Windows / macOS / Linux
- Un browser per accedere all'interfaccia (anche da altri dispositivi sulla
  stessa rete locale)

## Installazione

1. Scarica l'ultimo installer dalla pagina [Releases](../../releases)
2. Esegui l'installer per il tuo sistema operativo
3. Apri il browser sull'indirizzo indicato a fine installazione
4. Segui la guida di primo avvio in [`docs/GUIDA_UTENTE.md`](docs/GUIDA_UTENTE.md)
